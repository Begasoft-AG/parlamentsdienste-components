<Subheading>Start a new React project</Subheading>
<p>Start a new React project using Vite, Next.js, Nx, or your preferred React setup.</p>

<Subheading>Install the parlamentsdienste components from npm</Subheading>

<Source
    language="bash"
    code={`cd my-react-app
npm install @parlamentsdienste/pdcomponents-react`}
/>

<Subheading>Serve core assets as static assets</Subheading>
<p>
    Make sure the assets from the core library are served as static assets. If you use Vite, you can use the{' '}
    <code>vite-plugin-static-copy</code> plugin in your <code>vite.config.ts</code>:
</p>

<Source
    language="typescript"
    code={`
import { defineConfig } from 'vite';
import react from '@vitejs/plugin-react';
import { viteStaticCopy } from 'vite-plugin-static-copy';

export default defineConfig({
    plugins: [
        react(),
        viteStaticCopy({
            targets: [
                {
                    src: 'node_modules/@parlamentsdienste/pdcomponents-core/dist/parlamentsdienstecore/assets',
                    dest: '.',
                },
            ],
        }),
    ],
});
`}
/>

<p>
    If you use Next.js, you can copy the assets to the <code>public</code> folder with a postinstall script in your{' '}
    <code>package.json</code>:
</p>

<Source
    language="json"
    code={`
    "scripts": {
        "postinstall": "cp -R node_modules/@parlamentsdienste/pdcomponents-core/dist/parlamentsdienstecore/assets public"
    }
`}
/>

<p>Call this script after updating the library to ensure the assets are up-to-date.</p>

<Subheading>Add base styles and fonts</Subheading>
<p>
    Add these two lines to the main entry file, for example <code>main.tsx</code> or <code>layout.tsx</code>:
</p>

<Source
    language="typescript"
    code={`
import '@parlamentsdienste/pdcomponents-core/styles/parlamentsdienstecore.css';
import '@parlamentsdienste/pdcomponents-core/styles/typography.css';
`}
/>

<Subheading>Set the asset path</Subheading>
<p>
    Call <code>setAssetPath</code> in your main entry file, for example <code>main.tsx</code> or <code>layout.tsx</code>
    , to set the asset path for the components:
</p>

<Source
    language="typescript"
    code={`
import { setAssetPath } from '@parlamentsdienste/pdcomponents-core/components';

setAssetPath('http://localhost:5173');
createRoot(document.getElementById('root')!).render(<App />);
`}
/>
