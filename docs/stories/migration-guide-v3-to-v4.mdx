<Title>Migration Guide: v3.x to v4.0</Title>
<Subtitle>Move from version 3.x to 4.0 of the Parlamentsdienste Components library.</Subtitle>

<Subheading>Overview</Subheading>

Version 4.0 is a major update that introduces framework-specific wrapper libraries for Angular, React, and Vue. This
provides better integration with each framework's ecosystem, particularly for form handling.

<Subheading>Installation</Subheading>

In version 4.0, install the wrapper package for your framework. The core package is automatically installed as a
dependency.

#### Angular

<Source language="bash" code={`npm install @parlamentsdienste/pdcomponents-angular`} />

#### React

<Source language="bash" code={`npm install @parlamentsdienste/pdcomponents-react`} />

#### Vue

<Source language="bash" code={`npm install @parlamentsdienste/pdcomponents-vue`} />

The wrapper libraries automatically include the correct version of <code>@parlamentsdienste/pdcomponents-core</code> as a
dependency.

## Breaking Changes

<Subheading>1. Event Value Structure Change</Subheading>

-   **Affected components:** <code>pd-input</code>, <code>pd-textarea</code>, <code>pd-search</code>, <code>pd-slider</code>
-   **What changed:** These components now emit the value directly instead of wrapping it in an object with a <code>value</code>
    property. This change makes the API consistent with other components like <code>pd-dropdown</code> and
    <code>pd-combobox</code>.

<Subheading>Migration (Vue)</Subheading>

#### Before (v3.x)

<Source
	language="typescript"
	code={`
<pd-input @pd-change="onChange"></pd-input>

const onChange = event => {
const value = event.detail.value;
console.log(value);
};
`}
/>

#### After (v4.0)

<Source
	language="typescript"
	code={`
<pd-input @pd-change="onChange"></pd-input>

const onChange = event => {
const value = event.detail;
console.log(value);
};
`}
/>

**Why this change:** This change enables proper two-way data binding in the wrapper libraries and ensures consistent
behavior across all form components. It's particularly important for Angular's reactive forms and Vue's v-model support.

<Subheading>2. New selected Property</Subheading>

-   **Affected components:** <code>pd-dropdown</code>, <code>pd-combobox</code>
-   **What changed:** A new <code>selected</code> property has been added to support framework-specific value accessors and
    two-way binding.

<Subheading>Usage</Subheading>

#### Angular (reactive forms)

<Source
    language="jsx"
    code={`
<pd-dropdown [formControl]="myControl"></pd-dropdown>
// The selected property is handled internally by the Angular wrapper
`}
/>

#### Vue (v-model)

<Source
    language="jsx"
    code={`
<pd-dropdown v-model="selectedValue"></pd-dropdown>
// The selected property enables v-model support
`}
/>

#### React

<Source
    language="jsx"
    code={`
<PdDropdown selected={selectedItem} onPdChange={e => setSelectedItem(e.detail)} />
`}
/>

**Note:** For most use cases, you can continue using the <code>pd-change</code> event as before. The

<code>selected</code> property is primarily used internally by the framework wrappers for form integration.
